`Terrarium\Terrarium` is the single public class you interact with — a thin, typed facade over the Rust-backed `Terrarium\Runtime` engine primitive. All classes live under the `Terrarium\` namespace. The guest's language is decided entirely by which `*_guest.wasm` file you load; every method below is identical across JavaScript, TypeScript, Python, and PHP guests.

## Installation

Install via Composer (automatically declares the `ext-terrarium` requirement):

```sh
composer require eddmann/terrarium
```

Or require the library directly:

```php
require 'lib/Terrarium.php';
```

Then import the class you need:

```php
use Terrarium\Terrarium;

// or use fully-qualified names:
$t = new \Terrarium\Terrarium('quickjs_guest.wasm');
```

## Method summary

| Method | Signature | Description |
|---|---|---|
| `new Terrarium()` | `(string $path, ...)` | Load a guest wasm, set limits |
| `precompile()` | `static (string $path, ...): string` | AOT compile, return artifact bytes |
| `register()` | `(string $name, callable $fn): void` | Register a PHP callable as a capability |
| `eval()` | `(string $source, ?int $timeoutMs): mixed` | Run guest source, return result |
| `check()` | `(string $source, ?int $timeoutMs): array` | Validate without running |
| `analyze()` | `(string $source, ?int $timeoutMs): array` | `check()` + schema extraction |
| `output()` | `(): string` | Captured guest output from last eval |
| `types()` | `(string $format = 'dts'): string` | Generated SDK type declaration |
| `grant()` | `(mixed $resource): int` | Grant live object, get opaque handle |
| `resolve()` | `(int $handle): mixed` | Resolve handle to live object |
| `revoke()` | `(int $handle): bool` | Drop a granted handle |
| `manifest()` | `(): array` | Sorted registered capability names |
| `reset()` | `(): bool` | Drop persistent shared instance |
